# PawFolio Legal Website

Public, static legal pages for PawFolio, published with GitHub Pages.

The site provides English, Spanish (Latin America), and Thai versions of the
privacy policy, data deletion guide, and terms of service. The app links to
the pages in `PawFolio/Settings/Core/SettingsLegalLinks.swift`.

## Published URLs

- English: `https://danielcr12.github.io/PawFolioWebsite/`
- Spanish: `https://danielcr12.github.io/PawFolioWebsite/es-419/`
- Thai: `https://danielcr12.github.io/PawFolioWebsite/th/`

The legal copy should be reviewed against the release binary and App Store
privacy answers whenever PawFolio's data practices change.
